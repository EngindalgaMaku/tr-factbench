# Preview v0.1 evaluation files

These are the recommended evaluation files for new experiments in the `v0.1.0-preview` release. Both include the completed first independent blind-human review pass.

- `dev_general.jsonl`: 960 examples
- `dev_stress.jsonl`: 600 examples
- `domain/`: deterministic domain-specific views of the two preview files

Dev600 identifiers were normalized for the public preview. The mapping to archived experiment identifiers is available in `data/manifests/dev600_legacy_to_preview_id_map.csv`.

A second annotation pass and adjudication are planned for a future release.
